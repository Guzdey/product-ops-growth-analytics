# v0.3.0 全量运营指标报告

2026-09-03 使用 Retailrocket 官方完整数据完成 `v0.3.0` 指标计算。指标来源标记为
`data_origin='real'`，11 项阻断式指标质量检查全部通过，未使用桌面教学样例生成任何正式
结论。

| 项目 | 结果 |
|---|---:|
| 数据观察期（UTC） | 2015-05-03 至 2015-09-18，共 139 日 |
| 合格活跃访客 | 1,407,549 |
| 合格会话 | 1,761,606 |
| 指标注册项 | 31 |
| `mart` 指标关系 | 28 |
| 指标质量检查 | 11 pass / 0 warn / 0 fail |
| 成功的断点续算 | 205 秒 |
| DuckDB 增量 | 约 0.144 GiB |

“合格”表示指标计算排除了已标记的完全重复、未知行为、必要字段为空和交易 ID 规则异常，
但原始行仍完整保留在仓库中。

## 2. 核心指标

### 2.1 活跃与会话

| 指标 | 结果 | 应如何解释 |
|---|---:|---|
| 日均活跃访客 | 11,866.76 | 观察窗口内平均每天出现的去重匿名访客 |
| 单日 DAU 峰值 | 17,516 | 发生于 2015-07-26（UTC） |
| 滚动 30 日活跃峰值 | 369,351 | 当日及此前 29 日的去重匿名访客 |
| 单次 `view` 会话占比 | 78.03% | 大量会话在一次浏览后结束，是首屏承接的重要信号 |
| 两次 `view` 会话占比 | 11.36% | 第二常见路径仍未进入加购 |

这里的“首次观察访客”不等于注册用户，DAU/MAU 也不是账号体系下的产品粘性。

### 2.2 严格有序会话漏斗

只有后一个行为时间严格晚于前一个行为，才算完成对应步骤。

| 漏斗步骤 | 分子 | 分母 | 转化率/放弃率 |
|---|---:|---:|---:|
| 浏览后加购 | 36,512 | 1,755,714 个浏览会话 | 2.08% |
| 有效加购后购买 | 10,712 | 36,512 个有效加购会话 | 29.34% |
| 浏览后购买（不要求中间加购） | 12,453 | 1,755,714 个浏览会话 | 0.71% |
| 加购后无更晚交易 | 31,919 | 43,760 个含加购会话 | 72.94% |

从浏览到有效加购损失 1,719,202 个会话，占两步严格漏斗总损失的 98.52%。因此当前数据
支持先排查浏览到加购环节；但 Retailrocket 没有页面曝光、搜索词、价格和可用性之外的
商品语义，不能直接断言具体原因。

完成步骤的会话中，浏览到加购耗时中位数为 124 秒，P75 为 418 秒；有效加购到交易耗时
中位数为 262 秒，P75 为 539 秒；浏览到交易耗时中位数为 577 秒，P75 为 1,270 秒。

### 2.3 Cohort 活跃留存

总体留存使用可完整观察相应天数的 Cohort 人数加权，不把观察期不足的访客计为流失。

| 分群 | D1 | D3 | D7 | D14 | D30 |
|---|---:|---:|---:|---:|---:|
| 全部访客 | 2.760% | 0.893% | 0.561% | 0.321% | 0.157% |
| 首会话仅浏览 | 2.652% | 0.856% | 0.543% | 0.311% | 0.155% |
| 首会话加购未购 | 7.037% | 2.323% | 1.199% | 0.686% | 0.221% |
| 首会话购买 | 9.278% | 3.199% | 1.891% | 1.024% | 0.408% |

加购未购访客的 D7 留存确实高于仅浏览访客，但只高 0.656 个百分点；95% 置信区间约为
0.513–0.799 个百分点。该差异统计上清晰（双侧近似检验 `p≈3.91e-39`），却没有达到
预登记的 5 个百分点业务门槛。这正说明“统计显著”不等于“业务效应足够大”。

### 2.4 购买与复购

| 指标 | 结果 |
|---|---:|
| 唯一交易 `transactionid` | 17,672 |
| 交易事件行 | 22,457 |
| 购买访客 | 11,719 / 1,407,549（0.833%） |
| 复购访客 | 1,063 / 11,719（9.071%） |
| 每交易不同商品数（均值） | 1.263 |
| 每交易不同商品数（中位数/P75） | 1 / 1 |
| 相邻复购间隔（中位数/P75） | 0.0369 / 0.1778 日 |

数据没有商品购买数量和金额，因此“每交易不同商品数”不能解释为件单价、客单价或 GMV。
复购间隔很短，可能包含同一购物过程被拆成多个 `transactionid` 的情况，使用前需保留该
数据限制。

### 2.5 生命周期分群

主分群互斥；“流失风险”是额外标签。回访间隔 P75 为 8.10 日，因此代码向上取整后使用
9 日作为风险阈值。

| 主分群 | 访客数 | 占比 | 风险访客数 |
|---|---:|---:|---:|
| 首次会话跳失 | 1,203,127 | 85.477% | 0 |
| 活跃浏览未加购 | 165,699 | 11.772% | 152,162 |
| 加购未购 | 27,004 | 1.919% | 8,747 |
| 首次购买 | 10,656 | 0.757% | 9,892 |
| 重复购买 | 1,063 | 0.076% | 915 |

首次会话跳失人群不打“风险”标签，因为没有足够历史证明其曾形成持续活跃；这避免把所有
一次访问者都包装成可召回用户。

### 2.6 品类机会

品类 299 在 982 个浏览会话中有 11 个同品类交易会话，转化率为 1.120%，Wilson 95%
区间为 0.627%–1.995%。其同父级合格品类转化中位数为 3.239%，点估计差距为 2.119 个
百分点，因此达到 H3 的预登记门槛。

分类 ID 完全匿名。这个结果只能用于排序“进一步排查哪个匿名品类”，不能声称已找到某个
真实商品行业的问题，也不能把理论转化缺口写成可实现的新增订单。

## 3. 三项预登记假设

| 假设 | 结果 | 证据 |
|---|---|---|
| H1：加购未购 D7 留存比仅浏览高至少 5pp | 不支持 | 实际高 0.656pp，明显小于 5pp |
| H2：一个严格漏斗步骤贡献超过 60% 总流失 | 支持 | 浏览到加购贡献 98.52% 总流失 |
| H3：至少一个合格品类低于同级中位数 2pp | 支持 | 匿名品类 299 低 2.119pp |

没有因为 H1 未通过就修改分群、阈值或留存窗口。H2、H3 是描述性证据，不证明某项运营
动作会造成转化提升。

## 4. 可执行的运营建议

1. **优先优化首访到加购承接。** 先按匿名品类、会话深度和 `available` 状态拆分浏览到
   加购率，找出“流量大且意向形成弱”的区域；验证指标使用严格浏览到加购率，护栏指标
   使用会话退出和购买率。
2. **对加购未购人群做轻量召回测试。** 该人群 D7 留存高于仅浏览，但差距远小于原假设；
   应以随机实验验证提醒时机和内容，不能仅凭相关性判断召回有效。
3. **先人工审查匿名品类 299。** 检查时点可售状态、会话路径和样本稳定性，再决定是否
   值得进入品类优化实验；未经商品语义补充，不制作具体品类营销方案。

## 5. 数据质量与限制

- 918 / 2,756,101（0.0333%）事件被标记为完全重复并从指标分母排除，原始行未删除。
- 未知行为、必要字段空值和交易 ID 规则异常合计为 0。
- 事件时点 `categoryid` 覆盖率为 76.16%，`available` 覆盖率为 80.70%，任一可解释属性
  覆盖率为 83.99%。
- 有有效 `categoryid` 的事件均能关联分类树，关联率为 100%。
- 数据没有注册时间、页面曝光、真实商品名、价格、金额、渠道、成本或实验分组。

正式机器可读质量报告位于本地 D 盘 `exports/v0.3.0/metrics_quality_report.json`，不把
访客级明细或完整数据上传 GitHub。
