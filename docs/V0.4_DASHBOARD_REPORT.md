# v0.4.0 看板与真实运营闭环

## 1. 看板定位

本看板把 `v0.3.0` 的全量 SQL 指标转化为六页交互式运营分析。目标不是展示越多图越好，
而是让使用者依次回答四个问题：发生了什么、为什么值得关注、下一步做什么、如何证明
动作有效。

页面只读取 `mart` 聚合导出。SQL 仍是指标公式的唯一事实来源，Streamlit 负责筛选与
呈现，不直接扫描约 987.5 MB 原始 CSV，也不使用桌面教学样例得出结论。

## 2. 三条真实运营故事

### 故事 A：优先诊断浏览到加购

| 要素 | 定义 |
|---|---|
| 目标用户 | 有浏览行为、尚未形成有效加购的会话 |
| 触发时点 | 浏览商品后仍未发生严格更晚的加购 |
| 数据事实 | 浏览到加购贡献严格两步漏斗总流失的 98.52%，H2 超过 60% 门槛 |
| 运营动作 | 按匿名品类、会话深度和时点可售状态拆分，先检查高流量、低加购区域 |
| 核心指标 | 严格有序会话浏览→加购率 |
| 护栏指标 | 浏览→购买率、会话退出、数据质量覆盖 |
| 验证方案 | 对已定位的页面或信息方案做随机实验，比较加购率并监控购买护栏 |

解释边界：Retailrocket 没有页面曝光、搜索词、真实价格或商品文案，98.52% 只能决定
诊断优先级，不能直接证明流失原因。

### 故事 B：加购未购召回只做小规模测试

| 要素 | 定义 |
|---|---|
| 目标用户 | 首会话发生加购但未购买的匿名访客 |
| 触发时点 | 会话结束后进入预设召回窗口 |
| 数据事实 | D7 留存比首会话仅浏览高 0.656pp，95% 区间约 0.513–0.799pp |
| 运营动作 | 低成本、小流量测试提醒时机和内容，不直接全量长期触达 |
| 核心指标 | D7 活跃留存与购买访客率 |
| 护栏指标 | 触达频率、退订/投诉、重复购买口径稳定性 |
| 验证方案 | 随机分组并预先设定最小业务效应，报告效应大小、区间和 p 值 |

解释边界：差异统计显著，但未达到预登记的 5pp 业务门槛；观察数据也不能证明召回动作
会造成留存提升。

### 故事 C：匿名品类 299 进入人工诊断清单

| 要素 | 定义 |
|---|---|
| 目标对象 | 高流量但相对同级转化偏弱的匿名品类 |
| 触发时点 | 满足样本门槛且同级转化差距达到 2pp |
| 数据事实 | 品类 299 转化率 1.120%，比同父级合格品类中位数低 2.119pp |
| 运营动作 | 核查时点可售状态、会话路径、商品构成和区间稳定性 |
| 核心指标 | 同品类会话转化率与同级转化差距 |
| 护栏指标 | Wilson 95% 区间、交易会话量、相邻品类表现 |
| 验证方案 | 补充真实品类语义后再设计陈列或信息实验，不能直接套用营销方案 |

解释边界：品类 ID 完全匿名，机会分数只是排查排序，不代表可实现的新增订单。

## 4. 筛选与限制

- 时间筛选应用于日粒度活跃、会话和交易趋势；
- 首会话分群应用于留存曲线，Cohort 周范围应用于留存热力图；
- 根品类、最少浏览会话和机会候选筛选应用于商品与品类页；
- 漏斗、总体留存、生命周期、品类和质量的现有聚合表是完整观察窗口结果，不会因为侧栏
  日期变化而在前端伪重算；页面会明确注明有效范围；
- 数据没有金额、渠道、成本或实验分组，因此不展示真实 GMV、AOV、CAC、ROAS 或 LTV。

## 5. 公开演示数据

`demo_data/v0.4.0` 是 17 张真实聚合表的安全快照，总体指标保持全量结果；只截取高基数
路径和商品榜单。清单记录源运行 ID、行数、大小、选取规则和 SHA-256，并由测试确保没有
访客级、交易级或会话级标识。

## 6. 性能与验收

| 输入 | 首次读取 17 张聚合表 |
